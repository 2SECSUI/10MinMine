How rewards work

  1. Buy 10MM on Cetus using the live 10MM/SUI pool.
  2. Stake on Aftermath to enter the reward path.
  3. Every ~10 minutes a mine call advances the schedule.
  4. Mine-funded rewards flow to the farm.

Supply rules

Hard cap 21M. Genesis 50 is permanently locked. No extra minting beyond the block schedule. After the long emission era, new 10MM stops; trading and fee-based tips can continue.

Built for Sui

10MinMine uses Sui wallet standards and public network data. Check live balances and token activity on Sui.
