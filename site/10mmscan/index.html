10MMSCAN

Balance checker

Same job as Etherscan’s balance check tool, for 10MM on Sui: look up one address or many addresses and see current balances.

Paste one address, or a list (max 50 per lookup). No wallet connect needed for checks.

# Address 10MM SUI Notes
Read-only tool · uses public Sui RPC · configure packageId in ../config.js for 10MM lookups · never asks for keys.
